# TripTuner : AI Student Travel Planner

An AI-powered travel planning app built using Streamlit and HuggingFace.

## Features
- Travel style–based image gallery (random)
- Custom user instructions
- Travel modes: Solo / Friends / Family
- Budget breakdown
- Google Maps searchable locations
- Easy to use UI

## Run
pip install -r requirements.txt
streamlit run app.py
